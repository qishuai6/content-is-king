# Content Is King

## Overview

Use one skill to handle the full content workflow, but split execution into three explicit functional blocks.
Read [references/content-is-king-core.md](references/content-is-king-core.md) before substantial work so the output stays anchored to the source method.

## Core Rule

Treat content as storytelling, not raw information forwarding.
Do not stop at restating facts. Translate facts into tension, meaning, contrast, and consequence.

## Capability 1: 信息获取

Use this capability when the user needs source expansion, material gathering, topic mapping, or content fuel before writing.

### Goal

Build a wider and more useful input field than the obvious niche material alone.

### Do

- Collect the direct domain facts first.
- Add cross-domain references that can create fresh analogy or framing.
- Add audience tension: fear, desire, confusion, conflict, aspiration.
- Add proof points: scenes, examples, cases, quotes, numbers, failures, turning points.

### Output

- topic map
- source pack
- information inventory
- audience tension list
- cross-domain inspiration list

If the user's material is too narrow, say so and deliberately widen it before moving on.

## Capability 2: 找角度

Use this capability when the user already has material but needs a stronger take, hook, title direction, or narrative frame.

### Goal

Find an angle that feels both defensible and less obvious.

### Do

Run this sequence:
1. Write the obvious default take.
2. Reject that first-take framing.
3. Generate 3 to 5 alternative angles.
4. Select the one that is most grounded and most surprising.

Use these internal prompts:
- What will most creators say about this?
- What side is missing from the mainstream telling?
- Where is the contrast: expected vs unexpected, surface vs structure, winner vs overlooked person, event vs consequence?
- What would make the audience say "I did not expect that, but it tracks"?

### Output

- angle options
- hook directions
- title directions
- narrative reframes
- recommended main angle with rationale

Do not use fake contrarianism. Surprise must stay logical and earned.

## Capability 3: 内容创作

Use this capability when the user wants an outline, article, post, thread, script, or revised draft.

### Goal

Turn the chosen angle into content with movement, not flat exposition.

### Do

Build the draft with rising beats:
1. Open with tension, anomaly, reversal, or unresolved desire.
2. Add context without killing pace.
3. Escalate with stronger evidence or a sharper turn.
4. End with a changed understanding, not a mechanical recap.

When revising a weak draft:
- remove flat explanation
- add scenes, contrast, or consequence
- tighten transitions
- strengthen the strongest beat instead of making every section equally loud

### Output

- article outline
- short post
- longform article
- script outline
- full script
- rewrite with better rhythm

## Execution Rules

If the user asks for only one step, run only that capability.
If the user asks for full help, run the three capabilities in order.
If the user provides a draft, skip repeated discovery and focus on angle plus creation unless the draft is obviously under-informed.

## Value Guardrails

- Do not present borrowed information as original reporting.
- Do not fake authority in a domain the evidence does not support.
- Do not chase attention with sensitive provocation.
- Prefer grounded, humble, reader-serving framing.

## Default Response Shape

Unless the user asks for a different format, respond in this order:

1. `Step chosen`
State whether you are running 信息获取, 找角度, 内容创作, or the full workflow.

2. `Core story`
State the real story underneath the topic in 1 to 2 sentences.

3. `Work output`
Return the requested artifact for that step.

4. `Quality check`
Briefly verify:
- Is this more than information forwarding?
- Is the angle fresh but believable?
- Does the writing rise instead of staying flat?
- Is the value stance trustworthy?
