# 内容为王

`内容为王` 是一个 Codex skill。它把文章里的方法论，整理成一个可复用的大 skill，并在这个大 skill 里拆成 3 个功能：

- 信息获取
- 找角度
- 内容创作

这个 skill 基于文章：
- [从零到百万粉丝，我做 AI 这三年来总结的内容创作方法论！](https://www.uisdc.com/the-viral-playbook)

## 这个 Skill 是做什么的

它的作用不是简单“帮你写内容”，而是把一个主题、链接、草稿、趋势、笔记或零散想法，推进成更像内容成品的东西。

核心流程不是资料搬运，而是 3 步：

1. 先把素材池做宽
2. 再把角度找准
3. 最后把内容写出节奏

## 3 个功能

### 1. 信息获取

适合在写之前先扩素材。

常见输出：
- 选题地图
- 素材包
- 用户张力清单
- 跨领域灵感清单

### 2. 找角度

适合已经有材料，但角度还不够强的时候。

常见输出：
- 角度备选
- 开头钩子方向
- 标题方向
- 叙事重构方案

### 3. 内容创作

适合把角度正式落成大纲、文章、短帖或脚本。

常见输出：
- 文章大纲
- 改写稿
- 短内容
- 长文章
- 脚本

## 安装方式

如果希望 Codex 自动发现这个 skill，可以把它放到：

```bash
~/.codex/skills/content-is-king
```

这台机器上已经完成了这个链接。

## 调用示例

```text
Use $content-is-king 先帮我做信息获取，把这个选题的素材池整理出来。
Use $content-is-king 只帮我找角度，给我 5 个更强的切口。
Use $content-is-king 按完整流程，把这个主题写成一篇文章。
Use $content-is-king 帮我把这篇草稿改得更有节奏感。
```

## 工作流示意图

```mermaid
flowchart LR
    A["原始输入\n主题、链接、笔记、草稿、趋势"] --> B["信息获取\n扩素材、找张力、补证据"]
    B --> C["找角度\n否掉第一反应，生成备选角度，挑最强切口"]
    C --> D["内容创作\n大纲、成稿、改写、脚本"]
    D --> E["质量检查\n角度是否新鲜，内容是否有节奏，价值是否可信"]
```

## 设计原则

- 把内容当成讲故事，不当成信息转述
- 尽量扩大输入面，不只在单一领域打转
- 默认否掉第一个最普通的角度
- 成稿要有节奏，不要像说明书
- 价值观要稳，内容要可信
